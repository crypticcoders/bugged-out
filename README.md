# bugged-out

Local workspace synchronized with GitHub repository: [crypticcoders/bugged-out](https://github.com/crypticcoders/bugged-out)

## Automatic Sync
This repository includes an automatic synchronization script that monitors changes in this folder and automatically commits and pushes them to GitHub.

- **Start Auto-Sync**: Run `start-autosync.bat` or `./scripts/auto-sync.ps1`
- **Stop Auto-Sync**: Run `stop-autosync.bat`
